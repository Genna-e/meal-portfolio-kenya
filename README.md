# MEAL Portfolio — Virginia Ngami Paul

Monitoring, Evaluation, Accountability and Learning (MEAL) portfolio built to demonstrate results-framework design, data pipelines, and learning systems for donor-funded agricultural and resilience programmes in Kenya.

I am a Monitoring & Evaluation Specialist working with Kenya's Ministry of Agriculture & Livestock Development, building toward a Master's in GIS/geospatial analysis for agricultural development. This repository is a working demonstration of end-to-end M&E practice — from theory of change through to data collection, analysis, and adaptive learning — built around a single fictional programme so the pieces connect the way they would on a real assignment.

> **Note.** The Kitui Drought Resilience and Smallholder Income Programme (KDRSIP) referenced throughout is a fictional programme created for this portfolio. It is not a real project, and no real beneficiary data is used anywhere in this repository. It is modelled on the kind of drought-resilience and food-systems work implemented in Kenya's arid and semi-arid lands.

## Why these three pieces together

Most M&E portfolios show a dashboard in isolation, disconnected from the indicators it's meant to report on. This repository is built the other way round: the results framework comes first, the data pipeline is built to measure exactly those indicators, and the learning system shows how the findings would actually change programme decisions.

## Skills demonstrated

- Theory of change and logframe design (World Bank / OECD-DAC conventions)
- Indicator definition and Performance Indicator Reference Sheets (PIRS)
- Data quality assurance (validity, reliability, timeliness, precision, integrity)
- KoboToolbox survey design (XLSForm)
- Data cleaning and analysis in Python
- Dashboard design
- MEAL: learning agendas, reflection processes, adaptive management
